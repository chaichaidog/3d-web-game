# 霧境前線 · Block Outpost

一個給國中 Scratch 課使用的多人 3D 生存遊戲原型。老師建房，學生用暱稱與六位數房號加入。建議用電腦、鍵盤、滑鼠，老師與學生分別開啟同一個網址。角色、殭屍和武器使用原創 WebGL 2 網格模型，前後端由同一個 Node.js 程序提供，無外部遊戲素材或 CDN 依賴。

模型具有肩、肘、髖、膝關節，依移動距離播放步態，並有待機呼吸、追逐轉向、攻擊、受擊與倒地動作。三種武器使用不同槍身與槍管，第一人稱包含持槍手臂、行走擺動、後座回彈、換彈動作、短暫槍口效果、彈道與命中碎屑。射擊回饋會檢查學生積木、彈量、射速、安全區和暫停狀態。傷害與金幣由伺服器確認。遊戲下方的「音效開／音效關」可以切換合成音效。

[部署至 Render](https://render.com/deploy?repo=https://github.com/chaichaidog/3d-web-game)

## 部署

在 Render Dashboard 選 **New → Blueprint**，授權並選取此 GitHub repo 的 `main` 分支。設定私人的 `TEACHER_KEY` 作為老師開房密碼，套用設定。根目錄的 `render.yaml` 會建立一個免費方案的 Node Web Service。服務名稱若已被使用，可在建立時修改。

也可手動選 **New → Web Service**，Build Command 填 `npm ci --ignore-scripts`、Start Command 填 `npm start`，新增環境變數 `TEACHER_KEY`，Health Check Path 填 `/healthz`。單一 instance 運行，服務監聽 Render 提供的 `PORT`。請把服務網址與房號分享給學生，開房密碼留給老師。

## 本機試玩

使用 Node.js 22 或 24。執行 `npm start`，開啟 http://localhost:3000 。本機未指定 `TEACHER_KEY` 時，終端機會顯示此次啟動的臨時開房密碼。執行 `npm test` 驗證規則與連線。可以開三個獨立分頁模擬老師和兩位學生，請從網址新開分頁。

## 第一次上課

學生進房後會看到三段新手練習：接出 W、接上滑鼠射擊、命中第一個練習靶。積木面板會用文字和虛線指出下一個操作。教學可收起，學生按「查看新手教學」就能繼續。安全區地面的箭頭指向練習靶。

1. 老師切換到「老師開房」，輸入密碼後，把房號告訴學生。學生輸入暱稱和房號進入安全區。
2. 學生按 Tab，從「當按下開始時」接「重複無限次」，加入「如果…那麼」並選「W 被按住 → 向前移動」。按執行就能走。依此加入 S 後退、A 左移、D 右移。
3. 加「滑鼠左鍵按住 → 廣播『發射子彈』」。走出亮色安全圈再打靶。點遊戲畫面鎖定滑鼠，Esc 釋放，左右方向鍵也能轉向。每把武器會檢查射速與彈量。
4. 加「R 被按住 → 更換彈匣」或「彈匣是空的 → 更換彈匣」。可繼續設計衝刺、低血量治療。改程式、執行新版和買裝備都要回基地。「返回基地」是固定操作。
5. 老師按「開始下一波」。慢行、奔跑、重型或小型怪依波次組合，每第五波增加巨型感染者。每擊倒一隻普通怪，全隊每人拿 5 金幣。第一波單人場有三隻怪，打完就能買散光槍。
6. 自由生存中，走近金色補給箱可替全隊取得醫療包。據點防守中，怪會攻擊野外發電機，血量歸零可以重打。老師可切換模式、暫停、召回及查看學生視角和積木草稿。
7. 學生可舉手求助。老師看到的是以學生相機、房間狀態重繪的遊戲畫面，以及個人積木，不會擷取桌面或其他分頁。

## 80 分鐘帶課建議

| 時間 | 活動 |
| --- | --- |
| 0–15 分 | 開房、先走出第一步，再拼出其他方向 |
| 15–30 分 | 加射擊、換彈，出安全區打靶，合作完成自由生存第一波 |
| 30–45 分 | 回城購物，每人選一個改良，例如自動換彈或衝刺 |
| 45–70 分 | 切換據點防守，依進度挑戰第五波 BOSS |
| 70–80 分 | 展示自己的規則，從積木面板下載作品 |

## 保存與運作範圍

房間、金幣和程式存在單一伺服器記憶體。服務存活期間，同分頁重新整理會接回原角色。房間無操作兩小時、服務重啟或重新部署後，需重新開房。積木可下載 JSON，下次進入安全區後匯入並執行。每房最多 12 個角色席位，初版以 1–4 位學生為主要對象。建議上課前先開站測試學校網路，課程中避免重新部署。

伺服器每秒推進 20 次模擬，加入教室後使用同源 WebSocket 持續連線。學生約每 33 ms 傳送輸入，狀態獨立每 50 ms 推送，不需等待上一輪回應。連線中斷會重接；小幅位置校正平滑呈現，回城與暫停立即套用。其他角色以短暫緩衝平滑移動，斷線時限制外推距離。伺服器保管老師與學生權限、命中判定、商店與金幣。老師看得到教室內的角色與草稿，學生只收到同學的公開角色狀態。

場景與角色細節在載入時合併成可重用網格，每幀只調整關節，GPU instance 緩衝區重複使用。老師只繪製畫面中可見的學生預覽，預覽更新頻率低於學生自己的遊戲畫面。遊戲下方可選自動、流暢或精細畫質，並顯示實測 FPS 與連線延遲；自動畫質會依持續掉幀調整解析度。

WebSocket 使用固定版本 ws 8.23.0，原始執行檔與 MIT 授權放在 vendor/，不需 CDN 或額外建置下載。測試涵蓋持續推送、跨房間隔離、老師權限、重新連線、延遲平滑、回城、積木規則與模型快取。
